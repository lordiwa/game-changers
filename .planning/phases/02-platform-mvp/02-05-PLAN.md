    - **`streakAdvance`** (Pub/Sub `xp-events` SAME topic, separate subscriber): for each event_attended or challenge_progress message:
        1. Determine track: event_attended → `social`; challenge_progress for fitness type → `fitness`; content_completed → `knowledge`; etc.
        2. Read `/users/{uid}/streaks/{track}`. If `lastEventAt` was today → ignore (already advanced). If yesterday → currentDays++, lastEventAt=now. If 2+ days ago → check `shieldsRemaining`: if ≥1, decrement, lastEventAt=now (gap absorbed); if 0, reset currentDays=1.
        3. Reset shieldsRemaining to 1 every Monday (windowStartedAt rolls weekly).
        4. If currentDays > longestDays → longestDays = currentDays.
        5. Audit log.
