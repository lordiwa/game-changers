# Test PSS-4: ¿cuánto estrés estás cargando este mes?

La Escala de Estrés Percibido (PSS-4) es una herramienta validada internacionalmente para
medir cuánto estrés estás experimentando este mes. Es el mismo instrumento que usan
investigadores de salud pública en más de 50 países.

**Importante:** este test es una herramienta de autoconocimiento, no un diagnóstico.
Si el resultado te preocupa, considerá hablar con un profesional.

Para responder, pensá en las últimas 4 semanas. Cada pregunta tiene una escala del 0 al 4:
- **0** = Nunca
- **1** = Casi nunca
- **2** = A veces
- **3** = Bastante seguido
- **4** = Muy seguido
