# PSS-4 Quiz: how much stress are you carrying this month?

The Perceived Stress Scale (PSS-4) is an internationally validated tool for measuring how much
stress you are experiencing this month. It is the same instrument used by public health
researchers in more than 50 countries.

**Important:** this quiz is a self-awareness tool, not a diagnosis.
If the result concerns you, consider speaking with a professional.

To answer, think about the last 4 weeks. Each question has a scale from 0 to 4:
- **0** = Never
- **1** = Almost never
- **2** = Sometimes
- **3** = Fairly often
- **4** = Very often
